# Manager 与 Runner 镜像共用的 apt 包清单。
#
# 两个镜像都会执行 GitHub Actions job（Manager 在默认模式下、Runner 在容器模式下），
# 因此依赖必须一致。此前两个 Dockerfile 各写各的包列表，v1.1.0 只给 Runner 镜像补了
# git/build-essential/gnupg，Manager 镜像没同步，导致默认模式下 job 报
# "git: command not found"。改为单一清单后，依赖无法再单向漂移。
#
# === 基线：对齐 GitHub 托管 runner 的 apt 基础层 ===
#
# 来源：actions/runner-images 仓库 images/ubuntu/toolsets/toolset-2404.json 中的
#       apt.vital_packages + apt.common_packages + apt.cmd_packages（共 74 项）。
# 目的：为 runs-on: ubuntu-24.04 写的 workflow 迁到自托管时，不因缺基础命令而失败。
#
# 不包含语言与平台 SDK（Node、Python、Android 等）。那是托管镜像 40GB 体积的来源，
# 且版本因项目而异，应当由 workflow 里的 setup-* action 安装，或按
# examples/runner-images/ 的方式扩展出项目专用镜像。
#
# noble 上的唯一修正：
#   netcat -> netcat-openbsd
#     netcat 在 24.04 是虚包，netcat-openbsd 与 netcat-traditional 都提供它，
#     apt 无法自动二选一，必须写明。
#   （upx、libssl3、liblttng-ust1 同为虚包，但各自只有一个提供者，apt 能解析，保持原名）
#
# 有意排除（容器内无法工作，或默认源可能装不到）：
#   pollinate         Ubuntu 云实例熵种子服务，容器内无意义且会外联
#   systemd-coredump  容器内无 systemd
#   haveged           熵守护进程，现代内核不需要
#   ssh               元包会带入 openssh-server；容器内不跑 sshd，仅保留 openssh-client
#   p7zip-rar         multiverse 组件，基础镜像未必启用；p7zip-full 已覆盖常见场景
#
# 额外补入（不在上述三个 apt 列表中，但托管镜像同样具备）：
#   git               runner-images 用单独的脚本从 PPA 装特定版本，不走 apt 清单；
#                     缺它时 actions/checkout 会静默退化为无 .git 的 tar 包解压
#   build-essential   带入 libc6-dev 等，托管镜像经由各 -dev 包间接获得
#
# 全部包名已在 ubuntu:24.04 上用 apt-get install --simulate 整体验证可解析、无冲突。
# 每行一个包，# 开头与空行忽略。
